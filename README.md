# 朔记

一款简洁易用的个人记账工具，支持支出与收入记录，数据存储在浏览器本地，不会上传到服务器。

## 功能特性

- **快速记账** — 首页快捷记账，支持日期、金额、多级分类和备注，支出/收入一键切换
- **账单管理** — 完整账单明细列表，支持按分类、日期范围、交易类型筛选；长按卡片进入多选模式，支持批量删除；账单图标自动匹配分类图标
- **数据统计** — 多维度可视化分析，支持日支出/收入趋势（可独立控制各曲线显示）、大类占比、分类占比和支出对比，提供今日/本周/本月/本季度/上半年/今年/全部/自定义等时间周期切换
- **分类管理** — 内置常用分类模板，支持自定义增删改、颜色选取和拖拽排序
- **数据导入/导出** — 支持 CSV 和 JSON 格式的备份与恢复，CSV 导入自动检测格式（含/不含类型列），自动创建缺失分类并去重
- **桌面应用** — 基于 Tauri 2 构建，支持跨平台桌面端及 Android

## 技术栈

## 快速开始

### 环境要求

- Node.js 18+
- npm / pnpm / yarn

### 安装依赖

```bash
cd heima-accountant
npm install
```

### 开发模式

```bash
npm run dev
```

应用将在 `http://localhost:1420` 启动。

### 构建生产版本

```bash
npm run build
```

构建产物输出至 `dist/` 目录。

### 构建桌面应用（Tauri）

```bash
npm run tauri dev    # 开发模式运行桌面应用
npm run tauri build  # 构建桌面应用
```

## 数据说明

所有数据存储在浏览器 IndexedDB 中（数据库名 `ShuoAccountantDB`），包含两张表：

- `categories` — 分类数据（支持父子层级关系，区分支出/收入类型）
- `transactions` — 交易记录（支出/收入均支持）

首次启动时会自动初始化种子分类数据（餐饮、交通、购物、住房等 9 个支出一级分类及其子分类，以及工资、投资、兼职等 5 个收入一级分类及其子分类）。

## 导入导出格式

### CSV 格式

| 列名 | 说明 |
|------|------|
| 日期 | 支持 `2026-08-10`、`2026/08/10` 等格式 |
| 类型 | `支出` 或 `收入`（新格式含此列，旧格式默认为支出） |
| 金额 (元) | 正数金额 |
| 一级分类 | 分类名称，不存在则自动创建 |
| 二级分类 | 子分类名称 |
| 备注 | 可选备注信息 |

文件末尾含结余行，导入时自动跳过重复记录。

### JSON 格式

完整备份格式，包含所有分类和交易数据，导入时会覆盖现有数据。
